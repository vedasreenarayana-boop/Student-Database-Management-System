Student Database Management System

Project Overview
The Student Database Management System is a SQL-based project developed using MySQL to store, manage, and retrieve student information.

Objectives
- Maintain student records in a structured database.
- Perform CRUD operations on student information.
- Retrieve and filter records using SQL queries.
- Apply database management concepts through practical implementation.

Technologies Used
- MySQL 8.0
- SQL
- DBMS Concepts

Table Structure
The `students` table contains:
- student_id
- name
- age
- department
- marks

SQL Operations Implemented
- CREATE DATABASE and CREATE TABLE
- INSERT, SELECT, UPDATE and DELETE
- WHERE conditions
- ORDER BY and DISTINCT
- Aggregate functions: COUNT, AVG, MAX and MIN
- LIKE and BETWEEN operators
- GROUP BY
- ALTER TABLE

Project File
`student_management.sql` – Contains the SQL commands used in this project.

Learning Outcomes
- Practical understanding of SQL commands.
- Experience managing student records using MySQL.
- Understanding of CRUD operations and database queries.
